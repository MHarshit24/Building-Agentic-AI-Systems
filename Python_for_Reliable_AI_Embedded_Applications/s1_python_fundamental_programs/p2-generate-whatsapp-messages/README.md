# WhatsApp Message Generator 📱

A simple Python program to simulate the generation of shipping notification messages for customers using predefined order data.

## 📝 Problem Statement
- Write program that simulates generating a WhatsApp message to a customer regarding their order shipment. 
- Use the following dummy data:

## 📊 Dummy Data Used
The program processes the following information:

| Customer Name | Order ID | Shipping Address | Delivery Date |
| :--- | :--- | :--- | :--- |
| Ravi Kumar | ORD98765 | A-12, Sunrise Apartments, Opp. M.G. Library, Mall Road, Indore - 450021 | 15-Jan-2025 |

## ✨ Expected Output
When executed, the program generates the following message:

```text
Hello Ravi Kumar,

We are happy to inform you that your order ORD98765 has been successfully shipped on 15-Jan-2025 to:
A-12, Sunrise Apartments,
Opp. M.G. Library,
Mall Road, Indore - 450021

Thank you for shopping with us!
```
