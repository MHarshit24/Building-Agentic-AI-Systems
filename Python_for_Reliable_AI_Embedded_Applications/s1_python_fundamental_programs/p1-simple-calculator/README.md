## Practice Exercise-1: Simple Calculator

### Problem Statement
This program implements a simple arithmetic calculator using Python.  
It accepts two numbers from the user and performs basic arithmetic operations.

### Operations Performed
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Exponentiation
- Floor Division

### How to Run
1. Ensure Python 3.x is installed.
2. Navigate to the project directory.
3. Run the following command:

```bash
python main.py
