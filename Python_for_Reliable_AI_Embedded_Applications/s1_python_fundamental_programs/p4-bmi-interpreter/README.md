## Practice Exercise-4: BMI Interpreter

### Problem Statement
This program calculates a person's Body Mass Index (BMI) using their weight and height, and classifies the person based on standard BMI categories.

### Input
- Weight in kilograms
- Height in meters

### BMI Formula
BMI is calculated using the formula:

BMI = weight / (height × height)


### Classification
- Underweight: BMI < 18.5
- Normal weight: BMI ≥ 18.5 and BMI < 25
- Overweight: BMI ≥ 25 and BMI < 30
- Obesity: BMI ≥ 30

### Output
- BMI value (rounded to two decimal places)
- Classification based on the calculated BMI
