## Practice Exercise-5: Reverse Digits

### Problem Statement
This program reverses a given integer number and prints the reversed value.

### Input
- A single integer number

### Output
- The reversed number

### Example
- Input: 12345  
- Output: 54321

### How It Works
- The program extracts digits from the number one by one.
- Each digit is added to the reversed number using arithmetic operations.

### How to Run
1. Ensure Python 3.x is installed.
2. Navigate to the project directory.
3. Run the following command:

```bash
python main.py
