## Practice Exercise-3: Vowel Checker for Characters

### Problem Statement
This program accepts an alphabet from the user and determines whether it is a vowel or a consonant.
- The program validates input and handles invalid characters gracefully.

### Input
- A single alphabet character (a, e, i, o, u)

### Output
- Vowel
- Consonant

### Example
- Input: a  
- Output: Vowel

### How to Run
1. Ensure Python 3.x is installed.
2. Navigate to the project directory.
3. Run the following command:

```bash
python main.py
