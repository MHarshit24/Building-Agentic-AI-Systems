## Practice Exercise-6: Sum of Odd and Even

### Problem Statement
This program accepts an eight-digit number and calculates the sum of its even digits and odd digits separately.

### Input
- An eight-digit number

### Output
- Sum of the even digits
- Sum of the odd digits

### Example
- Input: 12345678  
- Output:  
  20  
  16

### How It Works
- Each digit of the number is processed individually.
- Even digits are added to the even sum.
- Odd digits are added to the odd sum.

### How to Run
1. Ensure Python 3.x is installed.
2. Navigate to the project directory.
3. Run the following command:

```bash
python main.py
