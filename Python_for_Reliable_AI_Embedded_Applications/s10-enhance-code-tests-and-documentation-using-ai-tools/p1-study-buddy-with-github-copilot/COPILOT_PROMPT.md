## Storing to persistent storage: Agent Mode

Analyze the codebase. We need to insert user query records in a Postgres database using SqlAlchemy. Refer .env for the connection properties. We need insert in the llm_queries_tbl, a autogenerated unique id (UUID), the user query, the LLM response, and the current timestamp in UTC.

1. Create a query model in db/query_model.py

2. Create db connection to store in Postgres in db/db_operations.py

3. Update main.py to perfrom insertion by calling the db_operations.py function

Ensure you make minimal change to the existing code that is running in production. Only update main.py to call function  in db_operations.py to perform the insertion.
