# GitHub Copilot Prompts Reference Guide

## Code Explanation: Ask Mode

```
Explain code in simple langauge. 
```

## Code Review: Ask Mode 

```
Review the code and share your observation.
```

## Documentation: Edit Mode

```
Add appropriate comments and docs Strings in the code.
```

## Test genaration

You need to generate unit test cases for the code. Analyse the code and share your plan to include unit test to achieve 70% test coverage - **Ask mode**

As per plan, write unit test for the code inside /test folder - **Agent mode**
